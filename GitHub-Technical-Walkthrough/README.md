# GitHub Technical Walkthrough

**TD SYNNEX Cloud Enablement Services · Instructor-led technical enablement · Live demos · Virtual delivery**

## Explore GitHub. Build your technical advantage.

A two-hour, demo-led introduction to GitHub: how git tracks change, how GitHub Enterprise is put together, and the collaboration, automation, AI, and security features that help teams ship better software faster.

Built for a mixed room: Microsoft partners building a GitHub practice, and customers modernizing how they ship software. No experience with git is needed.

## What you'll learn

- GitHub fundamentals and core concepts
- Repositories, branches, and pull requests
- How an enterprise organizes people, policies, and repositories
- GitHub Actions and automation
- Developer productivity with GitHub Copilot and Codespaces
- Keeping secrets out of your code
- Best practices for getting started with GitHub
